# Movement regression checks

```
node tools/tests/movement-checks.cjs              # all checks (about 6–12 minutes depending on the machine; `hsTouchCycle` alone runs about 2)
node tools/tests/movement-checks.cjs zones stops  # only some
```

Run from the repo root. Since Step 9 the guard patrols by default; the checks written before it switch patrol off to test the stationary guard (still a setting), and the `patrol…` checks switch it on. Since Step 10 the guard has a personality; every check before Step 10 runs with its influence off (the core AI), the `persona…` checks use profile A (Curious/Bored, Step 10's), and the `focCare…` checks compare profiles A / B / C. The script starts its own local server, opens `movement.html` in headless Chromium (Playwright; install with `npm i -D playwright` if it's missing) and checks the real controller, animator and posture code against limits taken from the approved movement. Run it after any change to movement, animation clips, the rig or tuning, and before testing on the phone.

## Fixed issues

- **Touch taps read as HOLD under load** (found while moving STATS to the top bar). The page could take 100–300 ms to acknowledge each simulated touch, and the tap helpers waited for that before timing their 80 ms press, so the browser sometimes saw a press over CQC's 0.45 s hold threshold. A tap became a HOLD (the reserved action), so a grab or RELEASE silently didn't happen. The helpers now send finger-up on time without waiting for finger-down to be acknowledged, and the game times the press from the events' own timestamps (`input.js`). `patrolTouch` jogs for 0.9 s of game time rather than wall-clock time (as `zones` does). No thresholds changed.

- **Knee jump on a sharp turn out of the crouch idle** (found by `jointPops`): starting to move reset the stride to the passing pose even while the turn-in-place steps were already showing the walk clip, so the legs jumped (≈19° at the back knee). Now the stride only resets when that jump would be invisible (`startPhaseSnap` in `animator.js`).
